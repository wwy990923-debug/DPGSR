# DP-GSR 算法完整总结

## 1. 整体框架

Dual-Path Group Sparse Representation (DP-GSR) 是一个**双路径组稀疏表示分类器**，由正向路径（inductive）和逆向路径（transductive）组成。

```
正向: T ≈ S × W    (测试样本被训练字典稀疏重构)
逆向: S ≈ T × D    (训练样本被测试字典稀疏重构)

融合: Score(k) = (1-α) × PF(k) + α × PR(k)
```

**关键发现**: 逆向路径不应作为独立分类器，而应作为**正向置信度验证器**。验证分 `verif = ||D(j, Ω_predF)||₂ / ||D(j, :)||₂` 是唯一需要的门控信号——它度量逆向是否同意正向的预测。

---

## 2. 正向路径 (Forward Inductive Path)

### 2.1 优化问题

```
X* = argmin_X  ||Y - AX||_F² + λ₁·||X||_G

组稀疏范数: ||X||_G = Σⱼ Σₖ ||x_{k,j}||₂
```

x_{k,j} 是测试样本 j 在类别 k 的训练原子上的系数块。

### 2.2 ADMM 求解

引入辅助变量 Q:
```
min_{X,Q}  ||Y - AX||_F² + λ₁·||Q||_G
subject to: X = Q
```

迭代更新:
```
1. X 更新:  X = (2A^TA + ηI)⁻¹ (2A^TY + ηQ - W)
2. Q 更新:  组软阈值
   q_{k,j} = max(0, 1 - λ₁/(η·||u_{k,j}||₂)) · u_{k,j}
   其中 U = X + W/η
3. W 更新:  W = W + η·(X - Q)
4. η 更新:  η = min(ρ·η, η_max)
```

参数: η₀=1.1, ρ=1.2, η_max=10²⁰, 收敛阈值 10⁻⁴

### 2.3 正向分类证据

类残差:
```
r_k(yⱼ) = ||yⱼ - A_k · x*_{k,j}||_2²
```

温度控制 Softmax:
```
PF(k|yⱼ) = exp(-r_k/τ_F) / Σᵢ exp(-r_i/τ_F)
τ_F = mean(r_1, ..., r_K)
```

---

## 3. 逆向路径 (Reverse Transductive Path)

### 3.1 优化问题

```
Z* = argmin_Z  ||A - YZ||_F² + λ₂·||Z||_R

行列组稀疏: ||Z||_R = Σⱼ Σₖ ||z_{j,Ω_k}||₂
```

z_{j,Ω_k} 是测试样本 j 对类别 k 训练样本的逆向系数行段。(1×n_k)

### 3.2 ADMM 求解

与正向对称，组结构按**行**（每个测试样本→各类训练样本）:
```
1. Z 更新:  Z = (2Y^TY + ρI)⁻¹ (2Y^TA + ρV - U)
2. V 更新:  行方向组软阈值
3. U 更新:  U = U + ρ·(Z - V)
4. ρ 更新:  ρ = min(1.2·ρ, ρ_max)
```

### 3.3 逆向分类证据

**原始论文公式** — 按类聚合的归一化激活:

```
a_k(yⱼ) = ||z*_{j,Ω_k}||₂

s̃_k(yⱼ) = a_k(yⱼ) / (√n_k · ||A_k||_F)

l̂_R(yⱼ) = argmax_k  s̃_k(yⱼ)
```

**伪后验概率** (归一化到和为1):
```
PR(k|yⱼ) = (s̃_k + ε) / Σᵢ (s̃_i + ε)
```

**逆向分类上限**: 约 48%（像素空间）。逆向是协同重建（所有测试样本一起重建每个训练样本），`argmax_k ||z_{j,Ω_k}||₂` 衡量的是"贡献量"而非"类别归属"。

---

## 4. 融合机制: 逆向验证分驱动融合

### 4.1 核心公式

逆向路径的正确用法不是产生一个独立分类分数 PR，而是产生一个**验证分数**来检查正向预测是否自洽:

```
verif(j) = ||Z(j, Ω_{pred_F})||₂ / ||Z(j, :)||₂
```

**物理含义**: 正向预测类 k_F 是否真的得到了逆向系数 Z(j,:) 能量的大头。verif ∈ [0,1]，越接近 1 说明两路径越一致。

### 4.2 融合决策规则

```
Algorithm: Verification-Gated Fusion

For each test sample j:

  Step 1: 正向预测 k_F = argmax_k PF(k|y_j)
  
  Step 2: 计算验证分
          verif = ||Z(j, Ω_{k_F})||₂ / ||Z(j, :)||₂
          
  Step 3: 决策
          if verif > θ:
              pred = k_F                          # 高验证 → 正向可信 → 采纳正向
          else:
              if PR_margin(j) > m₀:               # 低验证 + 逆向自信 → 正向可能错
                  pred = argmax_k PR(k|y_j)       # 采纳逆向
              else:
                  pred = k_F                      # 都不靠谱 → 保守选正向
```

**参数**: θ=0.65（验证分阈值，5-split 扫描最优），m₀=0.05（PR margin 阈值）

### 4.3 为什么验证分有效

验证分在不同的特征空间下的分离表现:

| 特征空间 | 维度 | 正向对时 verif | 正向错时 verif | 差距 |
|----------|------|---------------|---------------|------|
| 原始像素 | 2016 | 0.49 | 0.30 | 0.19 |
| PCA 50 | 50 | **0.79** | **0.38** | **0.41** |

- 正向对时，D(j,:) 能量 79% 集中在正向预测类（PCA-50）
- 正向错时，D(j,:) 能量分散，正向预测类只拿到 38%
- 差距 0.41，一个阈值 θ=0.6 即可近乎完美区分

### 4.4 与原始论文 α 公式的对比

| | 原始论文 | 本方案 |
|---|---|---|
| 门控信号 | SG（正向稀疏度） | **verif（正向-逆向一致性）** |
| 信号来源 | 只看 W | 同时看 W 和 D |
| 物理含义 | 正向系数是否集中 | 两路径是否互相印证 |
| 参数数量 | 1个 | 2个（θ, m₀） |
| 低维 gap | 极小 | **0.41** |

**原始公式 `α = 1-SG` 的三个缺陷**:
1. 单向门控——只看正向，不管逆向质量
2. PF 和 PR 各自 softmax 归一化，绝对量级丢失
3. 线性加权假设——两个物理来源不同的分数直接相加

验证分驱动融合同时解决了这三个问题。

### 4.5 逆向路径的正确角色

| 角色 | 效果 | 原因 |
|------|------|------|
| 独立分类器 (PR argmax) | ≤48% | 协同重建 ≠ 分类机制 |
| Z行KNN投票 | ≤46% | Z(j,i)是会计分配，不是相似度 |
| Z稀疏化后处理 | ≤46% | 稀疏化不改变根本机制 |
| **正向置信度验证器** | **有效** | 条件一致性检查，信息独立于 W |

## 5. 特征空间对融合效果的影响

### 5.1 核心发现

| 特征空间 | 维度 | 正向 | 逆向 | verif gap | 融合提升 |
|----------|------|------|------|-----------|----------|
| 原始像素 | 2016 | 88.6% | 47.3% | 0.19 | +0.04% |
| PCA 50 | 50 | 80.8% | 77.4% | **0.41** | **+0.98%** |
| Gabor | 500 | 79.9% | 46.4% | — | +0.56% |
| ResNet50 | 2048 | 76.7% | 28.0% | — | -0.10% |

**规律**: 验证分 gap 决定融合上限。gap 越大，融合越有效。低维 PCA 下正向和逆向实力对等，gap 最大化。

### 5.2 为什么低维空间验证分 gap 大

- **正向退化**: 50维 × 120训练样本表示 840 测试样本 → 欠定 → 残差分类弱
- **逆向增强**: 840 测试样本重构 120 训练样本 → 过定 → 稀疏约束有效 → 逆向结构清晰
- **验证分敏感**: 正向对时逆向高一致 (79%)，正向错时逆向明显不同意 (38%)

## 7. 参数建议

### 低维特征空间 (如 PCA-50)

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| λ₁ | 1e-1 | 正向正则化（低维时需要更强正则化） |
| λ₂ | 1e-2 | 逆向正则化（弱于正向，保留逆向结构） |
| θ (verif阈值) | **0.65** | verif>0.65 信正向，否则启动逆向检查 |
| m₀ (PR margin阈值) | 0.05 | 逆向自信心门槛 |

### 像素/高维特征空间

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| λ₁ | 1e-2 | 正向正则化 |
| λ₂ | 1e-2 | 逆向正则化 |
| θ (verif阈值) | 0.65 | 默认值，可根据特征空间微调 |

## 8. 理论依据

### 8.1 为什么验证分可以取代多层门控

```
像素空间 (gap=0.19):
  SG gap=0.01, qF gap=0.01, resRatio 方向反, PR_margin gap=0.012
  → 没有单一信号能区分 → 必须 5 层连乘勉强拼凑

PCA-50 (gap=0.41):
  verif gap 是上述任何信号的 20-40 倍
  → 一个阈值就能完成所有门控的工作
```

验证分的信息量 = 其他信号之和的倍数。不是"简化"，是信号质量本身就高到不需要复杂组合。

### 8.2 为什么低维空间验证分更好

正向和逆向在低维空间形成了**对称验证关系**:

```
正向: 欠定问题 → 120 样本表示 840 样本 → 残差弱 → 分类退化到 80%
逆向: 过定问题 → 840 样本表示 120 样本 → 稀疏好 → 分类接近 77%
验证: 正逆向对称 → 对正确的预测高度一致 → 对错误的一致拒绝
```

当正逆向准确率接近时，它们互为校验。当一强一弱时，弱者的意见没有校验价值。
