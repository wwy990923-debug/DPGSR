# DP-GSR 完整算法文档

## 1. 算法总览

DP-GSR (Dual-Path Group Sparse Representation) 是一个双路径组稀疏表示分类框架，包含：

```
Phase 1: 迭代自训练（扩充训练字典）
  - 运行 DP-GSR（正向+逆向+融合）
  - 用验证分 verif 筛选高置信样本
  - 将高置信样本+正向预测标签加入训练集
  - 重复至收敛

Phase 2: 逆向+融合收尾（处理剩余硬样本）
  - 用全量测试样本跑一次逆向
  - 对硬样本做硬开关验证分融合
```

单次 DP-GSR 内部结构：

```
正向路径 (Forward):  T ≈ S × W    → PF(k) = softmax(-残差)  → pred_F
逆向路径 (Reverse):  S ≈ T × D    → PR(k) = normalize(激活) → pred_R
融合 (Fusion):       verif + PR_margin 硬开关  → pred_final
```

其中：

| 符号 | 含义 | 维度 |
|------|------|------|
| S | 训练集 | d × N |
| T | 测试集 | d × M |
| W | 正向系数矩阵 | N × M |
| D | 逆向系数矩阵 | M × N |
| PF(k,j) | 正向后验代理：测试样本 j 属于类 k 的概率 | K × M |
| PR(k,j) | 逆向后验代理：测试样本 j 属于类 k 的概率 | K × M |
| verif(j) | 验证分：逆向是否同意正向的预测 | 1 × M |
| Ω_k | 类 k 的训练样本在 S 中的列索引集合 | — |

---

## 2. 正向路径

### 2.1 优化问题

正向路径用训练字典 S 稀疏重构测试样本 T：

```
min_W  ||S×W - T||_F^2  +  λ₁ × Σⱼ Σₖ ||W(Ω_k, j)||₂
```

其中 `W(Ω_k, j)` 是第 j 个测试样本在类 k 训练原子上的系数块。第二项是逐列组稀疏正则——每个测试样本倾向于只用少数几个类的原子来重构。

### 2.2 ADMM 求解

引入辅助变量 Q，约束 `W = Q`：

```
L_η = ||S×W - T||_F^2 + λ₁×||Q||_G + Tr(Y^T×(W-Q)) + (η/2)×||W-Q||_F^2
```

迭代：

```
1. W ← (2S^T×S + ηI)⁻¹ × (2S^T×T + ηQ - Y)
2. Q 按类分组做 L2 软阈值: q_{k,j} = max(0, 1 - λ₁/(η×||u_{k,j}||₂)) × u_{k,j}
3. Y ← Y + η(W - Q)
4. η ← min(1.2η, 10²⁰)
```

收敛条件: `||W - Q||_∞ < 10⁻⁴`，初始 η=1.1。

### 2.3 正向证据

对测试样本 j 和类 k，计算类残差：

```
RF(k,j) = ||T(:,j) - S(:,Ω_k) × W(Ω_k, j)||_2^2
```

温度控制 Softmax 得到正向后验代理：

```
PF(k|y_j) = exp(-RF(k,j) / τ) / Σ_i exp(-RF(i,j) / τ)
τ = mean(RF(:,j))
```

正向预测：`pred_F(j) = argmax_k PF(k|y_j)`

### 2.4 支持变长类别

`Forward.m` 的输入参数 `groupInfo` 既可以是标量 `nt`（等类样本数），也可以是标签向量 `S_label`：

```matlab
W = Forward(S, T, nt, lambda1)       % 等类: 按 nt 分组
W = Forward(S, T, S_label, lambda1)  % 变长: 按 S_label 分组
```

当传入标签向量时，Q 更新按 `S_label == classes(kk)` 索引，不依赖固定 nt。

## 3. 逆向路径

### 3.1 优化问题

逆向路径用测试 batch T 做字典，重构训练集 S：

```
min_D  ||T×D - S||_F^2  +  λ₂ × Σⱼ Σₖ ||D(j, Ω_k)||₂
```

其中 `D(j, Ω_k)` 是第 j 个测试样本对类 k 训练样本的逆向系数行段。第二项是逐行组稀疏正则——每个测试样本的贡献集中在少数类。

### 3.2 ADMM 求解

与正向对称，但组结构按行（每个测试样本→各类训练样本）：

```
1. D ← (2T^T×T + ρI)⁻¹ × (2T^T×S + ρV - U)
2. V 按类分组做 L2 软阈值（行方向）
3. U ← U + ρ(D - V)
4. ρ ← min(1.2ρ, 10²⁰)
```

初始 ρ=1.1，收敛阈值 10⁻⁴。

### 3.3 逆向证据

对测试样本 j 和类 k，计算归一化激活强度：

```
a_k(j) = ||D(j, Ω_k)||_2

SR(k,j) = a_k(j) / (√n_k × ||S(:,Ω_k)||_F)
```

其中 `n_k` 是类 k 的训练样本数，`||S(:,Ω_k)||_F` 是类 k 子字典的 Frobenius 范数。归一化消除类间能量偏差。

Softmax 归一化得到逆向后验代理：

```
PR(k|y_j) = SR(k,j) / Σ_i SR(i,j)
```

逆向预测：`pred_R(j) = argmax_k PR(k|y_j)`

### 3.4 支持变长类别

`Reverse.m` 的 `groupInfo` 同样支持标量 `nt` 或标签向量 `S_label`，D 的 V 更新按类别索引分组。

## 4. 验证分 (Verification Score)

### 4.1 定义

```
verif(j) = ||D(j, Ω_{pred_F(j)})||_2 / ||D(j, :)||_2
```

其中 `pred_F(j)` 是正向预测的类别。

### 4.2 物理含义

verif 衡量正向预测类在逆向系数 D(j,:) 中拿到了多少能量份额：
- verif 高（>0.65）→ 逆向也集中支持正向预测 → 正向可信
- verif 低（≤0.65）→ 逆向能量分散在其他类 → 正向可能错

### 4.3 区分力

在 PCA-50 特征空间 (K=38)：

```
正向正确时 verif 均值: 0.79
正向错误时 verif 均值: 0.36
差距 (gap):           0.43
```

是所有可用信号（SG、qF、resRatio、PR_margin、PR_bi、k-NN）中 gap 最大的。

在原始像素空间 (K=38)：gap 仅 0.19，效果有限。

## 5. 硬开关融合

### 5.1 决策规则

对每个测试样本 j：

```
verif = ||D(j, Ω_{pred_F})||₂ / ||D(j,:)||₂
PR_margin = PR(1) - PR(2)    // PR 的 top-2 gap

if verif > 0.65:
    alpha = 0                 // 高验证 → 正向可信 → 采纳正向
elif PR_margin > 0.05:
    alpha = 1                 // 低验证+逆向自信 → 正向可能错 → 采纳逆向
else:
    alpha = 0                 // 都不靠谱 → 保守选正向
```

最终分数：`Score(:,j) = (1-alpha)×PF(:,j) + alpha×PR(:,j)`

由于 alpha 只有 0 或 1，本质是硬切换而非连续加权。

### 5.2 参数

| 参数 | 推荐值 | 含义 |
|------|--------|------|
| θ | 0.65 | verif 阈值 |
| m₀ | 0.05 | PR_margin 阈值 |
| λ₁ | 1e-1 | 正向正则化 (PCA-50) |
| λ₂ | 1e-2 | 逆向正则化 (PCA-50) |

### 5.3 与原始论文的区别

| | 原始 DP-GSR | 最终方案 |
|---|---|---|
| 融合方式 | (1-α)PF + αPR，α 连续 | 硬开关，α ∈ {0,1} |
| α 来源 | α = 1 - SG（Hoyer 稀疏度） | verif + PR_margin |
| 信号来源 | 只看 W | 同时看 W 和 D |
| 物理含义 | 正向系数是否集中 | 正向-逆向是否一致 |
| 逆向角色 | 独立提供分类分数 | 正向置信度验证器 |

原始公式 `α = 1 - SG` 的三个缺陷：
1. **单向门控**：只看正向稀疏度，不管逆向质量。真正 mixture-of-experts 应双边评估
2. **伪校准**：PF 和 PR 各自 softmax 归一化，绝对量级信息丢失
3. **线性加权假设**：两个物理来源不同的分数直接加权平均

## 6. 迭代自训练管道

### 6.1 完整流程

```
Phase 1: 正向自训练

repeat:
    1. 运行 DP-GSR(S, T_unresolved)
       → 得到 W, D, PF, PR, pred_F, verif
    2. 选出 verif > 0.65 的测试样本
    3. if 无新增: 收敛, 跳出
    4. 将这些样本 + 正向预测标签加入训练集 S
       S ← [S, T(:,new)]
       S_label ← [S_label, pred_F(new)]

Phase 2: 逆向+融合收尾

    1. 用全量测试样本 T 做字典, 扩充后的 S 做目标
       跑一次 Reverse(T, S, S_label) → 得到 D
    2. 从 D 计算 PR
    3. 对剩余硬样本 (verif ≤ 0.65) 做硬开关融合
```

### 6.2 为什么 Phase 2 用全量测试做字典

逆向求解 `S ≈ T×D` 时，字典 T 必须足够大。

| 字典大小 | 效果 | 原因 |
|----------|------|------|
| 全量 2128 | 52.15%（硬样本） | 2128 > 1688 → 过定 |
| 仅 744 | 3.09% | 744 < 1688 → 欠定崩溃 |

高置信样本虽然自己不需要逆向判断，但必须留在字典里当参照物，帮助逆向重建训练集。

### 6.3 为什么 Phase 2 只跑逆向

自训练阶段已经确定了所有样本的正向预测：
- 已加入训练集的高置信样本：预测 = 伪标签
- 剩余硬样本：预测 = 最后一轮正向输出

Phase 2 只需要逆向系数 D 来计算 verif 和 PR_margin 做融合决策。

## 8. 关键设计决策

### 8.1 为什么验证分取代多层门控

实验证明，在 50+ 轮参数扫描 / 10+ 种信号探索中：
- SG gap=0.01, qF gap=0.01, resRatio 方向反, PR_margin gap=0.012
- verif gap=0.43 → 是其他信号的 20-40 倍
- 一个阈值就能完成所有门控的工作

### 8.2 为什么低维空间最好

PCA-50 下正逆向准确率接近（74.3% vs 74.1%），形成对称验证关系：
- 正向：50维 × 304 训练样本 → 欠定 → 退化
- 逆向：50维 × 2128 测试样本做字典 → 过定 → 稳定
- 验证分：对正确预测高度一致（79%），对错误一致拒绝（36%）

### 8.3 为什么保留 PR 的类归一化

去除 `√n_k × ||S_k||_F` 归一化使逆向独立准确率从 74.25% 提升到 75.52%（+1.27%），但融合效果从 80.59% 降到 79.32%（-1.27%）。归一化让类间 PR_margin 更均衡→逆向在更多硬样本上敢拍板→融合受益。

### 8.4 为什么 Phase 2 用全量测试做逆向字典

自信样本不需要逆向判断，但留在字典里帮助重建训练集 → 逆向对硬样本的分类更准 → pureREV 从 64 个增到 187 个。
