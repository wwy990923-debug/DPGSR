# Verification-Guided DP-GSR — 完整算法说明

## 一句话总结

逆向路径不做分类器，做**正向预测的验证器**。验证分 `v_j = ||D(j, Ω_{k_F})||₂ / ||D(j, :)||₂` 量化正向-逆向一致性。高验证→信正向；低验证+逆向自信→信逆向。高验证样本加入训练集自训练。

---

## 1. 符号表

| 符号 | 含义 | 维度 |
|------|------|------|
| S | 训练集 | d × N |
| T | 测试集 (batch) | d × M |
| K | 类别数 | 标量 |
| n_k | 类 k 训练样本数 | 标量 |
| Ω_k | 类 k 训练样本在 S 中的列索引 | — |
| W | 正向系数矩阵 | N × M |
| D | 逆向系数矩阵 | M × N |
| W(Ω_k, j) | 测试样本 j 在类 k 训练原子上的系数块 | n_k × 1 |
| D(j, Ω_k) | 测试样本 j 对类 k 训练样本的逆向系数行段 | 1 × n_k |
| PF(k\|y_j) | 正向后验代理 | K × M |
| PR(k\|y_j) | 逆向后验代理 | K × M |
| v_j | 验证分 | 1 × M |
| α_j | 硬开关融合系数 | {0, 1} |
| λ₁, λ₂ | 正/逆向正则化参数 | 标量 |
| θ, δ | 验证/置信度阈值 | 标量 |
| R_max | 自训练最大轮数 | 标量 |

---

## 2. 正向路径

### 2.1 优化问题

```
min_W  ||S·W - T||_F^2  +  λ₁ · Σ_{j=1}^{M} Σ_{k=1}^{K} ||W(Ω_k, j)||_2
```

第一项是重构误差，第二项是列方向组稀疏正则：每个测试样本倾向只用少数几个类的训练原子来重构。

### 2.2 ADMM 求解

引入辅助变量 Q，约束 W = Q，增广拉格朗日：

```
L_η(W, Q, Y) = ||S·W - T||_F^2 + λ₁·||Q||_G + Tr(Y^T·(W-Q)) + (η/2)·||W-Q||_F^2
```

迭代更新：

```
(1) W 更新:
    W^{(t+1)} = (2·S^T·S + η·I_N)^{-1} · (2·S^T·T + η·Q^{(t)} - Y^{(t)})

(2) Q 更新 (按类分组做 L2 软阈值):
    U^{(t)} = W^{(t+1)} + Y^{(t)}/η
    对每个测试样本 j、每个类 k:
    q_{k,j}^{(t+1)} = max(0, 1 - λ₁/(η·||u_{k,j}||₂)) · u_{k,j}

(3) Y 更新:
    Y^{(t+1)} = Y^{(t)} + η·(W^{(t+1)} - Q^{(t+1)})

(4) η 更新:
    η ← min(1.2·η, 10^{20})
```

初始 η=1.1，收敛条件 `||W-Q||_∞ < 10^{-4}`。

### 2.3 正向证据

```
类残差:
    RF(k, j) = ||T(:,j) - S(:,Ω_k) · W(Ω_k, j)||_2^2

温度控制 Softmax:
    τ_F = mean(RF(:,j))
    PF(k|y_j) = exp(-RF(k,j)/τ_F) / Σ_{i=1}^K exp(-RF(i,j)/τ_F)

正向预测:
    k_F = argmax_k PF(k|y_j)
```

## 3. 逆向路径

### 3.1 优化问题

```
min_D  ||T·D - S||_F^2  +  λ₂ · Σ_{j=1}^{M} Σ_{k=1}^{K} ||D(j, Ω_k)||_2
```

第一项是用测试集 T 做字典重建训练集 S 的重构误差，第二项是行方向组稀疏正则：每个测试样本的贡献集中给少数类。

### 3.2 ADMM 求解

引入辅助变量 V，约束 D = V，增广拉格朗日：

```
L_ρ(D, V, U) = ||T·D - S||_F^2 + λ₂·||V||_R + Tr(U^T·(D-V)) + (ρ/2)·||D-V||_F^2
```

迭代更新：

```
(1) D 更新:
    D^{(t+1)} = (2·T^T·T + ρ·I_M)^{-1} · (2·T^T·S + ρ·V^{(t)} - U^{(t)})

(2) V 更新 (按类分组做行方向 L2 软阈值):
    W^{(t)} = D^{(t+1)} + U^{(t)}/ρ
    对每个测试样本 j、每个类 k:
    v_{j,Ω_k}^{(t+1)} = max(0, 1 - λ₂/(ρ·||w_{j,Ω_k}||₂)) · w_{j,Ω_k}

(3) U 更新:
    U^{(t+1)} = U^{(t)} + ρ·(D^{(t+1)} - V^{(t+1)})

(4) ρ 更新:
    ρ ← min(1.2·ρ, 10^{20})
```

初始 ρ=1.1，收敛条件 `||D-V||_∞ < 10^{-4}`。

### 3.3 逆向证据

```
逆向激活强度:
    a_k(j) = ||D(j, Ω_k)||_2 = sqrt(Σ_{i∈Ω_k} d_{ji}^2)

类均衡归一化:
    s̃_k(j) = a_k(j) / (√n_k · ||S(:,Ω_k)||_F)

后验代理:
    PR(k|y_j) = s̃_k(j) / Σ_{i=1}^K s̃_i(j)

逆向预测:
    k_R = argmax_k PR(k|y_j)
```

归一化作用：消除类样本数偏差（√n_k）和类能量偏差（||S_k||_F）。虽然使逆向独立准确率微降（-1.3%），但让 PR_margin 更均衡→融合受益（+1.3%）。

### 3.4 支持变长类别

`Forward.m` 和 `Reverse.m` 的 `groupInfo` 参数既可以是标量 `nt`（等类样本数），也可以是标签向量 `S_label`（变长类别）。当传入标签向量时，组划分按 `S_label == classes(kk)` 索引，不依赖固定 `nt`。这使自训练管道中不同类加入不同数量的伪标签样本成为可能。

## 4. 验证分

### 4.1 定义

```
v_j = ||D(j, Ω_{k_F})||_2 / ||D(j, :)||_2
```

其中 `k_F = argmax_k PF(k|y_j)` 是正向预测。v_j ∈ [0, 1]。

### 4.2 物理含义

衡量正向预测类在逆向系数 D(j,:) 中拿到了多少能量份额：

- v_j 高（>0.65）：逆向能量集中在正向预测类上→两路径一致→正向可信
- v_j 低（≤0.65）：逆向能量分散在其他类→正向可能错

### 4.3 区分力

在 PCA-50 特征空间 (Yale B, K=38, n_k=8)：

```
正向正确时 v_j 均值:  0.79
正向错误时 v_j 均值:  0.36
差距 (gap):          0.43
```

这比其他任何单路径信号大 20-40 倍：

```
SG gap ≈ 0.01,  qF gap ≈ 0.01,  resRatio gap ≈ 0.01,  PR_margin gap ≈ 0.012
```

在原始像素空间，gap 缩小到 0.19（正向 0.49 vs 错误 0.30），解释为什么高维空间融合增益有限。

## 5. 硬开关融合

### 5.1 决策规则

```
ΔPR_j = PR[1] - PR[2]        ← 逆向预测的 top-2 置信度差距

if v_j > 0.65:
    α_j = 0                   ← 高验证 → 正逆向一致 → 信正向
elif ΔPR_j > 0.05:
    α_j = 1                   ← 低验证+逆向自信 → 正向可能错 → 信逆向
else:
    α_j = 0                   ← 都不靠谱 → 保守选正向
```

最终分数：

```
Score(:,j) = (1-α_j) · PF(:,j) + α_j · PR(:,j)
l̂_j = argmax_k Score(k,j)
```

由于 α_j ∈ {0,1}，每个样本要么由正向分类，要么由逆向分类。不存在连续加权。

### 5.2 为什么用硬开关

1. PF 和 PR 是物理含义完全不同的分数（残差 vs 激活），连续加权导致尺度错配
2. 逆向在多数样本上弱于正向→连续 α 倾向于压碎 alpha→融合靠运气
3. 硬开关物理可解释：每个样本的决策路径透明（"信正向"还是"信逆向"）
4. 只有两个阈值参数，跨数据集零调参

### 5.3 退化性质

```
θ→0 或 δ→1  →  纯正向 (SRC 退化)
θ→1 且 δ→0  →  纯逆向
```

## 6. 自训练管道

### 6.1 算法流程

```
输入: S, S_label, T, λ₁, λ₂, θ=0.65, δ=0.05, R_max
输出: l̂ (1×M)

U ← {1, ..., M}              ← 未解决样本索引
l̂ ← 0_{1×M}

// Phase 1: 自训练
for r = 1 to R_max:
    正向求解 (S, T(:,U)) → W, PF
    逆向求解 (S, T(:,U)) → D, PR
    计算 v_j = ||D(j, Ω_{k_F})||₂ / ||D(j,:)||₂  ∀j∈U
    C ← {j∈U | v_j > 0.65}    ← 高置信样本
    if |C| = 0: break          ← 收敛
    
    for j ∈ C:
        k_F = argmax_k PF(k|y_j)
        S ← [S, T(:,j)]        ← 加入训练集
        S_label ← [S_label, k_F]
        l̂_j ← k_F
        U ← U \ {j}

// Phase 2: 收尾
逆向求解 (S, T) → D, PR   ← 全量测试做字典
for j ∈ U:
    重新计算 v_j, ΔPR_j (现在 D 对应全量 T)
    按硬开关规则确定 α_j 和 l̂_j

return l̂
```

### 6.2 为什么 Phase 2 用全量测试做字典

自训练后训练集 S 从 N 膨胀到 N'（>1000）。逆向求解 `S ≈ T·D`：

```
仅用硬样本做字典:  字典原子 = U  < N'  → 欠定 → 崩溃 (准确率 ~3%)
全量测试做字典:    字典原子 = M  ≥ N'  → 过定 → 有效 (准确率 ~52%)
```

高置信样本虽然自己不需要逆向判断，但留在字典里作为参照物→帮助逆向更准确地重建训练集→间接提升硬样本的逆向分类。

### 6.3 为什么 Phase 2 只跑逆向

正向预测已在 Phase 1 中确定：
- 加入训练集的样本：预测 = 加入时的伪标签
- 剩余硬样本：预测 = 最后一轮正向输出

Phase 2 只需 D 来计算 v_j 和 PR_margin 做最终融合决策。

### 6.4 R_max 参数

| R_max | 含义 |
|-------|------|
| 1 | 单次融合，无自训练 |
| 2 | 最多 2 轮自训练（AR 推荐） |
| ∞ | 收敛为止（Yale B 推荐，通常 3-7 轮） |

---

## 7. 参数

| 参数 | 推荐值 | 含义 |
|------|--------|------|
| λ₁ | 1e-1 | 正向组稀疏正则化 (PCA-50) |
| λ₂ | 1e-2 | 逆向组稀疏正则化 (必须弱于 λ₁) |
| θ | 0.65 | 验证分阈值 |
| δ | 0.05 | PR margin 阈值 |
| R_max | 1 或 ∞ | 自训练轮数 |
| ADMM: η₀, ρ₀ | 1.1 | 初始惩罚参数 |
| ADMM: growth | 1.2 | 惩罚增长因子 |
| ADMM: ε | 1e-4 | 收敛阈值 |
| ADMM: max iter | 500 | 最大迭代次数 |

跨数据集 (Yale B → AR) 所有参数无需重调。

## 9. 核心发现

1. **逆向不能做分类器**：协同重建本质限制，上限 ~48% (像素) / ~74% (PCA)
2. **但能做验证器**：v_j gap=0.43 (PCA-50)，是其他信号的 20-40 倍
3. **硬开关替代连续 α**：避免异质分数尺度错配，两个阈值跨数据集通用
4. **自训练在正向弱时最有效**：正向 50-75% 是甜区
5. **低维 PCA 是最佳特征空间**：正逆向平衡 → verif gap 最大化
6. **最后用全量测试做逆向字典**：硬样本的脸留在字典里当参照物

## 10. 与原始 DP-GSR 的区别

| | 原始 DP-GSR | 最终版 |
|---|---|---|
| 融合方式 | (1-α)PF + αPR, α 连续 | 硬开关, α∈{0,1} |
| α 来源 | 1 - Hoyer(W) | verif(D, PF) + PR_margin |
| 信号来源 | 只看 W | 同时看 W 和 D |
| 物理含义 | 正向系数是否集中 | 正向-逆向是否一致 |
| 逆向角色 | 独立分类器 | 正向置信度验证器 |
| 自训练 | 无 | 迭代扩充训练字典 |
| 超参数 | SG (Hoyer 指数) | θ, δ (两个阈值) |
| 变长类别 | 不支持 | Forward.m / Reverse.m 支持标签向量 |
